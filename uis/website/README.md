# Nexova Corporate Website

This project contains the public-facing company website for Nexova Solutions.

## Scripts

- `npm install`
- `npm run dev -- --host 0.0.0.0`
- `npm run build`

## Goals

- Showcase the company’s business lines and value proposition.
- Highlight hiring, training, and support services.
- Reflect the company’s visual identity and operating tone.
- Provide a public homepage at `/` built from reusable UI components.
