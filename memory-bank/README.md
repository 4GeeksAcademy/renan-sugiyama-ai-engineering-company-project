# Memory Bank

This folder stores the project context that should remain stable and easy to reference during development.

## Included files

- [product-context.md](product-context.md) — business and product context
- [technology-stack.md](technology-stack.md) — technology stack and repo conventions
- [project-state.md](project-state.md) — current status of the project

## Purpose

The memory bank is intended to keep the most important project facts in one place without requiring repeated reading of the full repository.
